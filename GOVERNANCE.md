- `docs-governance/` is a separate root-level directory for governance, technical memory, gates, handoffs, standards, learning records, validation packets, and registries.

## Authority boundary

Google Drive is intended to be the authoritative system for editable project artifacts and their operational version history. GitHub is authoritative for technical governance, website source and deployment, structured policies, durable handoffs, and reproducible evidence. The bootstrap registries in GitHub are staging records until the Google Drive register is created and reconciled.
