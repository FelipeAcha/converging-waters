## Purpose

Carry the useful structural findings from the parallel school-research conversation into the canonical monitoring architecture without duplicating the school census itself.

## Imported structural findings

- citizen-science design should not be organized only by administrative district;
- useful hierarchy: `district → populated center / microcuenca → schools → students → nearest monitoring node / river question`;
- Yanahuara should be a node separate from Urubamba for citizen-science and monitoring design;
- Pachar is a strategic node because Hatun Mayu reaches the Vilcanota there;
- Ollantaytambo requires finer attribution because Patacancha crosses the local system before joining the main stem;
- a post-Ollantaytambo main-stem point can function as a candidate outlet station for the first corridor;
- Huarocondo is a candidate satellite citizen-science branch because it lies within the wider Hatun Mayu sub-basin;
- main-stem longitudinal schools and tributary/microcuenca schools should be modeled as two superposed participation networks.

## Verification boundary

The supplied synthesis contained source references. Before promotion into the website or canonical factual claims, the following were independently checked during the receiving workstream:
- Yanahuara is an official centro poblado of Urubamba;
- institutional/research sources recognize the Yanahuara microcuenca;
- Gobierno Regional Cusco states that Hatun Mayu reaches the Vilcanota at Pachar;
- ANA technical documentation lists `PGIRH-067 Pachar` as an `EHA` hydrological automatic station;
- Ollantaytambo municipal material states that Patacancha reaches Ollantaytambo and joins the Urubamba.

Important correction preserved: `PGIRH-067 Pachar` is currently evidenced as a **hydrological station**, not automatically a water-quality station.
